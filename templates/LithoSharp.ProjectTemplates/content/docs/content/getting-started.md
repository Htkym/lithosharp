# Getting started

Add Markdown files beneath `content`. Give each page a `title`; `description`
and `order` are optional. Nested filenames become distinct generated IDs.

## Build and preview

Run `dotnet run` from this project directory, or use the matching LithoSharp CLI
to build and preview the saved output. Custom C# schemas are checked during
compilation and site builds.
