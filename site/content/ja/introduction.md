LithoSharp は、C# によるサイト設定、型付きコンテンツ、Markdown を組み合わせます。
このハンドブックの対象は開発中の 3.0 系列です。
選定した候補はリポジトリのバージョン一覧で確認できます。
ローカルビルドの成功は、リリースが公開されたことを意味しません。

最初に[このサイトのビルド手順](../quickstart/)を読み、[機能一覧](../features/)からガイドを選んでください。
英語と日本語のハンドブックは、文書 ID と `3.0` バリアントを共有します。
言語切り替えでは対応する文書に移動します。このサイトは現在の内容を古いバージョンとして掲載しません。

このサイトは公開パッケージの API を
[WebsiteFactory.cs](https://github.com/Htkym/lithosharp/blob/main/site/WebsiteFactory.cs) で使っています。
ハンドブックでは、文書用 Markdown プロファイル、範囲を分けた検索、型付きのコンポーネント属性を使います。
別のサンプルページでは C# から生成したスキーマと入力カタログを使います。
知識セクションは独自のポリシーを持つ OKF リーダーを使っています。

既存の 2.x サイトでは、依存関係を置き換える前に [3.0 への移行](../migration/)を読んでください。
移行中は既存の出力と公開時点の基準を保持します。
