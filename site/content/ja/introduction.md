LithoSharp は、技術文書、API リファレンス、Open Knowledge Format（OKF）バンドルを扱う C# と .NET の静的サイトジェネレーターです。
Markdown 文書の要件を C# で定義し、ビルド時に検証して、静的ファイルとして公開できます。

## まずはここから

初めて使う方は Docs テンプレートで[ドキュメントサイトを作成](../quickstart/)してください。
.NET 10 SDK が必要です。Markdown のみのサイトでは、Node.js や React は不要です。

既存サイトを更新する場合は、パッケージを変更する前に[移行ガイド](../migration/)を確認してください。

## 作成できるサイトと主な機能

ドキュメントサイトでは、ナビゲーション、目次、ローカル検索、多言語表示を利用できます。
技術ガイドと一緒に、.NET XML ドキュメントや OpenAPI 定義から生成した API リファレンスを公開できます。

ローカルの [OKF 0.2 と 0.3 のバンドル](../knowledge/)を検証し、元のバイト列を保持してエクスポートしたり、Docs に表示したりできます。この機能はプレビューです。

ブログや単独のページも作成できます。対話的なコンテンツには MDX と React を使えます。

各機能の設定、例、制約は[機能ガイド](../features/)で確認できます。

## 文書の作成から公開まで

C# スキーマでコンテンツの要件を確認し、出力の品質チェックで生成された HTML やリンクを検証します。
それぞれ検証する範囲が異なるため、コンテンツの型が正しくても、公開するリンクがすべて有効とは限りません。
公開前にサイトをビルドし、出力を確認してください。

詳しい使い方は[型付きコンテンツ](../typed-content/)、
[ドキュメントと多言語対応](../documentation/)、[API ドキュメント](../api/)へ進んでください。
