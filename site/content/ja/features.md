| 機能 | ガイドと実行用ソース | 条件 |
|---|---|---|
| 型付き Markdown とネイティブ YAML | [型付きコンテンツ](../typed-content/)、`WebsiteModels.cs` | DTO と入力ルートの宣言が必要。対応する YAML は一部 |
| 生成スキーマ、カタログ、参照 | [型付きコンテンツ](../typed-content/)、生成される `GeneratedExamples` | 入力集合の変更後は再ビルドが必要。カタログは公開の証明ではない |
| 条件付きルールと文書参照ルール | [型付きコンテンツ](../typed-content/)、`WebsiteFactory.cs` | カタログの根拠が不明または不完全なら判定を保留 |
| Markdown プロファイルと C# コンポーネント | [プロファイルとコンポーネント](../profiles/)、`VersionBadge` | プロファイルと登録を明示。属性はリテラル値のみ |
| Docs レイアウト、ルート、範囲別の検索 | [文書と言語](../documentation/)、ハンドブックコレクション | コレクション、バージョン、言語で識別。外部検索サービスは有効にしない |
| 翻訳リビジョンとスニペット | [検証](../operations/)、`checks/` | レビュー済みハッシュと、対応付けた信頼するテストを明示 |
| OKF バンドルとバイト列の保持 | [知識](../knowledge/)、`knowledge/` | 適合性、鮮度、信頼性のポリシーを分離 |
| API リファレンス | [API 文書](../api/)、選択したパッケージのメタデータとコンパイラーの XML | 同じ公開 ID と翻訳した説明。XML がない場合は明示 |
| Core アセット、任意の PNG 処理、ソーシャル画像 | [画像](../images/)、`website-social` 変換 | 寸法と変換を明示。PNG コーデックの制限あり |
| CLI、エディター、LSP | [開発ツール](../tooling/) | 信頼したビルドや検査は、入力中の操作とは別に実行 |
| ビルドグラフ、診断、公開 | [運用](../operations/) | 検証の成功と公開の成功は異なる根拠 |
| テンプレート、MDX、移行、テスト | [追加のワークフロー](../extended/) | 各文書に従い、追加パッケージ、信頼する Node 環境、明示したフィクスチャが必要 |

リポジトリの[機械可読な対応表](https://github.com/Htkym/lithosharp/blob/main/site/feature-coverage.json)は、
固定した機能 ID を公開 API、英日両方のページ、サンプルソース、制限事項に対応付けます。
このサイトで実行するサンプルと、既存サンプルで示すワークフローを区別しています。
一覧への掲載は考えられるすべての設定をテストしたことを意味しません。

[詳細ガイドの索引](../../reference/ja/README/)はリポジトリにある正式な原稿とパッケージの文書を再利用します。
英日ペアの原稿ごとに、レビューしたリビジョンを明示します。
API の一覧は選択したパッケージから生成します。
CLI のコマンド、エディターの設定、テンプレート、診断、公開 API の契約ファイルは、
ソースの一覧に記録し、変更時に明示的なレビューが必要になるようにします。
