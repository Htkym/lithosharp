`DocumentationSite` は、二つの `DocumentVariant` を持つ `handbook` コレクションを登録します。
`3.0/en` の入力は `en/`、`3.0/ja` の入力は `ja/` に出力します。
共通の文書 ID が言語間の移動先を結び、明示した `MissingDocumentPolicy.Error` がペアの欠落を拒否します。
バージョンを追加する場合は、専用の入力ソースとルートの接頭辞が必要です。
ラベルを付けても、現在の文章が過去の文書になるわけではありません。

`DocsSiteTemplate` と `DocsPageLayout` がナビゲーションとページ構造を提供します。
`Browser.Search = true` は、現在のコレクション、バージョン、言語ごとのローカル検索を有効にします。
検索データには、描画したコンポーネントや取り込んだソースも含め、最終的に公開するページ本文を使います。
入力として検出しただけでは、下書きを検索に公開しません。
このサイトは Algolia や解析用エンドポイントを登録しません。

言語切り替えで、同じ文書の英語版に移動できます。
サイドバー、目次、通常のリンクでも移動できます。
JavaScript によるページ移動を使わなくても、公開 HTML は利用できます。
アクセシビリティの確認では、生成した出力で検索とキーボード操作を確認してください。

`translation-reviews.json` は、レビューした英語と日本語の正確なバイト列のハッシュを記録します。
`DocumentTranslationReview` はこの記録を使い、ビルドは記録を更新しません。
原文や翻訳を変更すると、明示的に再レビューするまで記録は古い状態になります。
これらの記録は技術的な正しさを証明しません。
