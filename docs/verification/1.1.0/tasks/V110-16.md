## 実装

- 対象command：`LithoSharp: Build`、`Start Server`、`Stop Server`、`Inspect Site`。
  Migration GUI commandは追加しない。`Open Preview`はpreview実装（V110-18）と共に来る。
- `src/serveController.ts`：project単位の状態機械
  （Stopped/Starting/Running/Rebuilding/Failed/Stopping）。遷移は実process・eventからのみで、
  固定sleepによる起動成功判定はない。同じprojectのStart連打は1 processにまとめ、
  別projectは分離する。実URL・port・generationを保存し、portを仮定しない。
  stdoutは増分decodeし、分割された日本語とJSON行を扱う。
  正常停止は構造化stdin shutdownを使い、timeout後のみ所有treeを回収する
  （Windowsはtaskkill/T、POSIXはprocess group）。利用者の外部serveを所有扱いしない。
- `src/buildRunner.ts`：build/check/inspectのJSONを契約で読む（`{`判定や成功文言の
  正規表現なし）。同時書込みbuildを直列化し、失敗はexit・error・診断を分けて返す。
  Build押下をpublish承認と解釈しない。
- 大きなlogは有界buffer・fileへ送り、OutputChannelへ無制限に溜めない。
- 依存復元・外部link check・factory実行の許可範囲は表示のみで、明示操作なしに実行しない。
- 全handlerはtrust gateを通す。clear/reload/deactivate時はcontroller破棄で停止する。
