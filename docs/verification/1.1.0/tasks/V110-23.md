## 実装

- 拡張にMDX worker管理を追加した（`src/worker.ts`、unit test 10件）。
  `lithosharp.workerDirectory`の明示設定が最優先で、空なら同梱lockfileのhash付き
  拡張storageを使う。`LithoSharp: Restore MDX Worker`が同梱sourceを写して
  `npm ci --ignore-scripts --no-audit --no-fund`を実行し、LSPを再起動する。
  利用者project・global npm状態・利用者npm設定には触らない。未復元でも
  Markdown診断は動き、MDXは理由付きで出ない。worker配置は`initializationOptions`で渡す。
- `.vscodeignore`を新設し、配布物からtest・eng・node_modules・fixture・検証状態を除外した。
  `eng/stage-worker.mjs`がworker sourceとlockfileを`resources/worker/`へ写し、
  lock hash付きmanifestを作る。`vsix:pack`はcompile・staging・送信なしpackまで行う。
- `publish-extension.yml`を新設した。`extension/lithosharp-vscode/*` tagではpack・検証のみ行い、
  公開は手動dispatchと`marketplace`環境承認の両方が必要である。publisher未設定では閉じて失敗する。
- `Test-ReleasePipeline.ps1`がtrigger分離・dispatch＋承認gate・version/tag整合・pack経路の
  公開command混入・誤tag guardの存在を検査する。
- `Validate-Package.ps1`のstrict mode継承不具合を修正した（依存なしnuspecの`dependencies`参照と空配列列挙）。
