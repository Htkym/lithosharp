## runner構成

- `eng/Run-MigrationCorpus.ps1`：取得→原本build→route収集→解析/変換→手動patch記録→候補build→serve検証を独立stage化し、各stageのcommand・network・exit・input/output hash・stdout/stderr hashを残す。
- `eng/Collect-MigrationRoutes.mjs`：原本buildのHTMLと`.docusaurus` metadataからtyped route oracleとsource対応表を作る。raw exactとは別にV110-20の正規化page set比較へ渡す。
- `eng/Merge-MigrationRouteOracles.mjs`：locale別snapshotを統合し、route分類の衝突を拒否する。
- `eng/MigrationReplay/`：宣言したclean文書範囲だけの候補buildと、loopback serveでの代表操作（page、navigation、asset、search index）を行う。
- 手動patchは適用せず、対象元fingerprint・span・理由・機能低下・再実行条件を`manual-patches.json`に残す。

## 実装中の修正（runner・収集器）

- Windows bind mountではLinux実行bitが付かずyarn postinstallが落ちるため、`/source`を名前付きvolumeに移した。
- tmpfsの`/tmp`がyarn build-script実行をEACCESで壊すため、volume上の`/wintmp`へ`TMPDIR`を向けた。
- `.docusaurus`が最終localeで上書きされるため、原文buildはlocale別に分離した。
- metadata permalinkの末尾slash有無、`@site/versioned_docs/...`形式のsource表記の取りこぼしを修正し、prettier 2件→89件、jest 全件分類に改善した。
- serve判定をblog/docsで分け（blogは本文・見出し・公開日、docsはsidebarとnavigation）、blogの誤検出をなくした。
- WindowsのMAX_PATH対策（`core.longpaths`）、原文buildのgit履歴要求（full clone）、jestの生成準備（`fetchSupporters`、hash記録）、docusaurusのlockfile準拠installとpackage buildをrunnerへ織り込んだ。
