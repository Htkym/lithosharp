## 実装

- `eng/measure-editor.mjs`：実Release LSP binaryを実`LspClient`経由で駆動する計測harness。
  50KiB代表Markdown/MDXでwarm後100編集×burst/spaced、debounce込みend-to-endを記録する。
  soakは二root 1,000編集＋途中server kill→有界再起動（上限3、説明付き停止）。
- `tests/integration/`：実Extension Host（VS Code 1.139.1）で動くsmoke。
  project選択→設定保存、開く→LIT001、編集で修正→stale消失→再導入で再出現を固定した。
- 製品修正（実Hostで発覚した不具合）：
  - `package.json`の`main`が`./out/extension.js`を指し活性化失敗していた。正しい`./out/src/extension.js`へ修正。
  - `restrictedConfigurations`がproperty配下の不正位置にあった。configuration直下へ移動。
  - Windowsの`.cmd/.bat` launcherは`cmd.exe`経由で起動する（`src/process.ts`＋unit test）。
  - VS Code境界で診断のcode/sourceを落としていた。`toVsDiagnostic`で保持する（unit test追加）。
  - LSP重要度（1=Error起点）をVS Code重要度（0=Error起点）へ変換する。従来はWarningがInformation表示だった（unit test追加）。
