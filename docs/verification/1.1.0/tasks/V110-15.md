## 実装

- 最小構成：manifest・`LithoSharp: Select Project`・OutputChannel・StatusBar・設定・disposables。
  拡張versionは0.1.0系列。`engines.vscode`は`^1.139.0`（使用APIは安定版のみ、実機1.139.1で確認。
  型定義は直近公開の1.138.0を使用する旨を記録する）。
- activationは`onLanguage:markdown/mdx`とcommandに限定し、無関係workspaceでは起動しない。
  MDX grammarや既存Markdown拡張の上書きはない。
- project候補はcsproj等の静的内容から検出する（LithoSharp参照の有無をテキスト照合）。
  MSBuildのimport/condition評価はしない。曖昧な場合は一覧から選択を保存する。
- multi-rootはworkspace folder＋project pathをkeyとし、同名csprojを混同しない。
- Workspace Trustをlimited宣言し、未信頼時は非実行検出と説明のみにする。
  build/serve/LSP/restore相当のhandlerは全てtrust gateを通す（直呼びtestで固定）。
  実行path設定はrestricted configurationにする。
- CLI解決は明示設定、project localのtool manifest、global PATHの順で、解決自体は実行しない。
  versionは明示選択時に1回だけ問い合わせる。採用path/versionは表示する。
- 依存不足は状態表示と操作可能な理由にする。自動installやglobal設定の上書きはしない。
- 設定変更・project削除・workspace切替・deactivateで所有資源を破棄する。
  telemetryは実装しない。
