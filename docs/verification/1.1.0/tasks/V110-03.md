### 新設した契約

```json
{
  "schemaVersion": "1.0",
  "success": true,
  "exitCode": 0,
  "tool": { "name": "LithoSharp.Tool", "version": "1.0.0" },
  "core": { "name": "LithoSharp", "version": "1.0.0" },
  "project": { "resolved": false, "coreVersion": null, "reason": "..." },
  "contracts": [ { "name": "DiagnosticCodes", "maturity": "Stable", "schemaVersion": "1.0", "description": "..." } ],
  "capabilities": [ { "name": "document-inspection", "maturity": "Stable", "schemaVersion": "1.0", "description": "...", "scope": ["markdown", "..."] } ],
  "error": null
}
```

- capability は `document-inspection`（言語と段階）、`versioned-snapshot`、`serve-shutdown`、`source-route-lookup` の4つ。すべて Stable、schema 1.0。
- `document-inspection` は `markdown` / `mdx` と `syntax` / `front-matter` / `project-resolution` / `generated-output` / `runtime` を scope に持つ。project 無しで実行できる段階と、明示操作が必要な段階を区別する。
- tool に同梱された Core と project が参照する Core を別 field にし、未解決の `project.coreVersion` は `null` のままにする。
- 交渉規則：未知 field と未知 capability は無視、必須 capability の欠落は `Require` が説明付きで失敗、schema は major 一致で互換（先行 minor 許容）、major 不一致は拒否。
- Editor 結果の identity field 名（`workspaceId`、`projectId`、`documentUri`、`documentVersion`、`projectGeneration`、`languageKind`、`analysisStage`、`completion`）と、診断位置の変換規則（公開 1-based / LSP 0-based UTF-16）を仕様として固定した。実装は V110-10〜V110-17。
