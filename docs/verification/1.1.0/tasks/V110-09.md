## 対応表（手順1/2）

- 範囲は維持する。独自拡張の追加実装はしない。
- 台帳：`eng/verification/1.1.0/markdown-compat.json`（機械可読）。取得元・固定version/hash・
  ライセンス/帰属・総example数を記録する。
  - CommonMark 0.31.2（https://github.com/commonmark/commonmark-spec、CC-BY-SA 4.0）と
    GFM 0.29-gfm（https://github.com/github/cmark-gfm、CC-BY-SA 4.0）の公式spec.txtは
    vendoredせず、`not-run`として可視化する（`vendoredExamples: 0`）。
  - Markdig参照は1.3.2（`tests/LithoSharp.MarkdigComparison/*.csproj`）で
    `UseAdvancedExtensions + DisableHtml` のshadow比較に限定し、製品描画には使わない。
  - Litho側は`SpecVersion=commonmark-0.31.2+gfm-0.29`、`ImplementationVersion=2`を台帳へ固定する。
- 分類はsupported-pass / supported-fail（0件）/ intentional-divergence /
  unsupported（13件）/ not-runの5分類で、分母は
  `total = executed + not-run`、`executed = pass + fail + divergence + unsupported` とする。
  supportedのみの合格率を全準拠率と呼ばない（台帳`totals.fullComplianceClaim: false`）。
- 機械的対応：`MarkdownCompatLedgerTests` が台帳の`sources`・`classifications`・
  `cases`（11件）を実行し、HTML・診断・advisory ON/OFF・fixture実在を検証する。

## Advisory検査（手順4/5/6）

- opt-inで3件を追加する。既存LIT001（脚注・Warning）のID/既定severity/挙動は維持する。
  - LIT003 定義リスト（U02）、LIT004 汎用属性（U13）、LIT005 grid table（U12）。
    いずれもInfoで、旧CLIの既定終了codeは変えない（`check` の失敗閾値は既定Error）。
  - 高確度のみ：定義リストはterm行＋最大1空行＋`: `内容（`:::`除外）、
    汎用属性は`{#`/ `{. `＋識別子＋`}`（200字以内）、gridは`+---+`境界＋近傍の境界/`|`行。
    曖昧な単独行（`{#}`、`+---+`単独、`: `なし等）は警告しない。
  - 共有scan：fence追跡＋inline code blanking（複数backtick対応）＋backslash escape除外を
    3診断で共有する。文書全体への正規表現だけでは判定しない。
  - 各IDは文書先頭の1件のみ（重複なし）、位置は1-based行列、未対応理由と安全な代替を message に付ける。
  - 描画は変えない。`Compile` のHTMLはON/OFFで同一（テストで固定）。

## CLI明示検査と検査option（手順7）

- 新検査option：`DocumentInspectionOptions.EnableCompatibilityAdvisory`（既定false、加算）。
  有効時のみ`LithoLimits.FindCompatibilityAdvisories`を追記し、既存診断とID重複させない。
- CLI明示検査：`lithosharp markdown-compat <file> [--advisory on|off] [--format text|json]` を追加し、
  同じ`DocumentInspection.Inspect`に接続する。project評価・build・Node/restoreを起こさない。
- 契約：`CompatibilityAdvisoryOption.TryParse` が`on`/`off`のみ受理し、未知値はfalse（CLIはusage error・exit 2）。
  C# testでON/OFF/未知を固定し、CLI実動作は`logs/cli-*.txt`で確認する。
  - off/text：`No compatibility diagnostics.`、exit 0
  - on/text：LIT003/004/005の3行、exit 0
  - on/json：単一JSON document、exit 0
  - code例（fence/inline内）は警告なし、exit 0
  - `--advisory bogus` / `--format xml` はexit 2
