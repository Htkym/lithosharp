# V110-20 — migrationの比較範囲・URL差・機能差を可視化する

実施日：2026-09-29（日本時間）

対象成果物：LithoSharp Core / Tool

## 実装

- 既存のpath配列`expectedRoutes`、CLI `missing`/`extra`、verdict、summary、exit codeを維持した。
  report schemaは`1.0`のまま加算fieldを追加した。
- `MigrationRouteOracle`を追加し、routeごとの`kind`、locale facet、任意の除外理由、原本version/base pathを受け取る。
  従来の文字列配列はkind未分類として扱い、exact比較だけを行う。oracleなしは`NotCompared`で、空の差分を成功扱いしない。
- `MigrationRouteComparisonReport`に原本route総数、対象route数、重複数、除外数・分類・理由、locale別数、原本version、source tree hash、oracle hashを追加した。
  source versionはoracleの宣言値を優先し、なければ`package.json`の`@docusaurus/core`を読む。hashは解析対象の相対pathと各file SHA-256から算出する。
- exact raw public-path比較は従来どおり既定動作とし、`--compare-normalized-pages`で文書page set比較を追加する。
  source base pathと`--base-url`のpathはsegment境界でのみ除去し、末尾slash、strict UTF-8 percent encoding、Unicode NFCを正規化する。比較はordinalで大文字小文字を区別し、case-foldや二重decodeはしない。
- route oracleは従来のJSON文字列配列と、`sourceVersion`、`basePath`、`routes[{path,kind,locale,reason}]`を持つobject形式を受け付ける。
  CLI/APIともに同じreport builderを使い、`routes.comparison`は旧CLI consumer向けに加算fieldとして出力する。
- `DocusaurusProfile`に既知のmanual component差を追加した。ThemedImageの外観変更、zoom/video/tweetの操作変更、UpgradeGuide/ColorModeToggle/raw-loaderの静的化、react-liveの削除、未知theme importの未検証を分類する。
  機能同等と誤認しないよう既知の差は`NotEquivalent`、未知は`Unverified`とし、自動適用候補にはしない。
- `SuggestedAction`のfingerprint、行span、適用条件は維持し、手動component所見がある文書の候補は自動適用不可になる。
- `PublicAPI.Unshipped.txt`を更新し、日英migration guideとCLI referenceにoracle形式・比較範囲・正規化規則を記載した。

## 既知の制限

- 従来のpath配列oracleは種類を推測しないため、normalized document page set比較の分母に使わない。分類付きobject oracleを用意する。
- component分類はソース内の静的なimport/JSX markerを対象とする。動的JavaScript設定や未検証componentは実行せず、未検証のまま扱う。
- route matchは宣言された文書page setの一致であり、原本サイト全体の機能同等性を示さない。
