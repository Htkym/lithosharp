# Test and validation review for 1.1.0

This change removes checks that cannot detect a product defect, shares costly setup where the asserted behavior is the same, and keeps representatives of distinct failure paths. The decision is based on the realistic bug a deletion would miss. Test counts and coverage percentages are not deletion targets.

Production sources, package versions, locks, and shipping payloads are unchanged. The review covers Core, language-server and Markdig tests, VS Code unit/protocol/integration support, MDX worker tests, reference/browser fixtures, `eng/Test-*.ps1`, benchmark entry points, migration verification, and CI orchestration. Test declarations and fixture purposes were inventoried; candidate bodies and their relevant production callers were inspected. This is a scoped source review, not a claim that every assertion or fixture byte has been independently proved.
