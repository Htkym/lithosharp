# 性能

[English](performance.md)

速度は参考値です。利用環境・構成・コンテンツによって変わります。

対象は100ページのDocsです。入力読み込みと品質検査を含むサイト生成の既存値で、外部HTTP検査は含みません。

| 操作 | 参考時間 |
| --- | ---: |
| 初回生成 | 約1.23秒 |
| 変更なし | 約0.45秒 |
| 本文1ページ変更 | 約0.58秒 |
| レイアウト変更 | 約1.07秒 |

過去の結果を丸めた値であり、3.0 の候補を測定した結果ではありません。
NuGet の復元と C# のコンパイルは含まず、ビルド全体の時間を示すものではありません。
現行版を評価する場合は、マシン、入力、プロファイル、検証の設定をそろえ、全体ビルド、キャッシュを使うビルド、編集後のビルドを分けて測定してください。
[ビルドグラフ](build-graph.ja.md)と[増分ビルド](incremental-builds.ja.md)を参照してください。
