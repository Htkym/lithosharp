# 性能

[English](performance.md)

速度は参考値です。利用環境・構成・コンテンツによって変わります。

対象は100ページのDocsです。入力読み込みと品質検査を含むサイト生成の既存値で、外部HTTP検査は含みません。

| 操作 | 参考時間 |
| --- | ---: |
| 初回生成 | 約1.23秒 |
| 変更なし | 約0.45秒 |
| 本文1ページ変更 | 約0.58秒 |
| レイアウト変更 | 約1.07秒 |

既存の結果を丸めた値であり、2.2.0で新しく測定した結果ではありません。NuGetの復元とC#のコンパイルは含まず、ビルド全体の時間を示すものではありません。
