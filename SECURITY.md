# Security Policy

## Supported versions

PageSharp is in the `0.x` series. Security fixes are made against the latest
released version. There is no long-term support for older `0.x` releases while the
API is still stabilizing.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting instead: open the repository's
**Security** tab and choose **Report a vulnerability**. This opens a private
advisory visible only to the maintainers.

When reporting, include as much of the following as you can:

- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept.
- Affected version(s) and environment.

We will acknowledge the report, investigate, and keep you updated on progress. Once
a fix is available, we will coordinate disclosure and credit reporters who wish to
be named.
