## Documentation-first static sites

LithoSharp renders Markdown into a static documentation site. The Docs template
shows a directory-based sidebar, the current page in the center, and a table of
contents on the right.

## Content organization

Folders under `content` become sidebar sections. Each Markdown file becomes a page.
Set `sidebar_position` to control order and `sidebar_label` to use a label other than
the page title.
